# Tanbih

A lightweight, cross-platform prayer-time notification CLI.

## Requirements

- Go

## Development

Run the application:

```bash
go run ./cmd/tanbih
```

Display version information:

```bash
go run ./cmd/tanbih --version
```

Run tests:

```bash
go test ./...
```

Build:

```bash
go build -o dist/tanbih ./cmd/tanbih
```
